# fram-food-webshop
A responsive, sustainable food delivery webshop connecting customers with local farms in Norway, featuring product browsing, a map of farm locations and an AI-powered chatbot for customer support

## Project Description

This project is a responsive webshop for a sustainble delivery service in Norway. The website connects customers with fresh produce from local farms and highlights sustainbility, local agriculture and ease of use.

The project was developed as part of an exam assignemnt and follows a provided Figma design. It includes a main landing page, a product listing page, a newsletter form, a map showing partner locations and an AI powered customer service chatbot interface.

## Technologies used

- HTML5
- CSS
- JS
- Google Maps API
- OpenAI API (chatbot interface- simulated)
